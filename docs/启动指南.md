# BiliTools 启动指南

本文说明如何在本机把项目跑起来。BiliTools 是一个 Python 工具集，提供 **PySide6 桌面 GUI**、**命令行入口**和 **后端 SDK** 三种用法；GUI 与 SDK 跑在同一个进程里，启动 GUI 即启动完整应用，不需要单独开后端服务。

---

## 1. 环境要求

| 项目 | 要求 |
|---|---|
| Python | 3.11 及以上（推荐 3.12 / 3.13，本项目在 3.13 上验证通过） |
| 操作系统 | Windows（无边框窗口、AppUserModelID 等针对 Windows 适配；SDK 本身跨平台） |
| 网络 | 首次扫码登录、调用 B 站接口需要联网 |
| ffmpeg | **无需手动安装**。优先用系统 ffmpeg（在 PATH 中）；没有则自动回退到 `imageio-ffmpeg` 内置的静态二进制 |

---

## 2. 安装依赖

在项目根目录执行（虚拟环境名固定为 `venv`，与打包脚本 `build_exe.bat` 保持一致）：

```bash
cd D:\project\bilibili-project\BiliTools

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

macOS / Linux 把激活命令换成 `source venv/bin/activate`。

主要依赖说明：

- `PySide6==6.11.1` — 桌面 GUI，仅启动图形界面时需要
- `requests`、`python-dateutil`、`certifi` — B 站 API 请求与登录
- `websocket-client` — 直播弹幕长连接
- `qrcode`、`pillow` — 扫码登录二维码
- `imageio-ffmpeg` — 音视频合成兜底
- `pandas`、`openpyxl` — 历史记录导出 xlsx

> 如果只跑后端 SDK 或 CLI、不启动界面，可以不装 `PySide6`，但 `requirements.txt` 里带了也无妨。

## 3. 启动方式

### 3.1 桌面 GUI（推荐）

```bash
python -m frontend.pyside6
```

等价入口：

```bash
python bilitools_gui.py
```

启动后默认进入首页。首页提供统一搜索框（输入 BV 号 / av 号 / B 站链接，回车后跳转到下载页并预填）以及设置、下载管理、工具箱三个入口。标题栏左侧的小房子图标可随时返回首页。

### 3.2 命令行 CLI

```bash
python main.py --help                      # 查看全部命令
python main.py info BV1ov42117yC           # 标题、UP 主、播放/弹幕/评论数、标签
python main.py summary BV1ov42117yC        # 视频 AI 总结
python main.py video BV1ov42117yC          # 下载视频并合成音频
python main.py cover BV1ov42117yC          # 下载封面
python main.py comments BV1ov42117yC       # 查看评论
python main.py export-comments BV1ov42117yC  # 导出评论
python main.py rank                        # 热门视频
```

### 3.3 Python SDK

```python
from src.services import LoginService, VideoService
from src.models import VideoQuality

# 首次执行扫码登录，cookie 会被保存，后续自动复用
LoginService().qr_login()

service = VideoService()
info = service.fetch_info("BV1ov42117yC")
print(info.title, info.owner.name)

result = service.download_video_with_audio("BV1ov42117yC", quality=VideoQuality.P1080)
print(result.path, result.cached)
```

更多可运行示例见 `examples/README.md`，例如：

```bash
python examples/quick_start.py     # 扫码登录 + 下载一个视频（完整流程）
python examples/video.py           # 仅查询视频信息
python examples/dynamic.py         # 动态解析
```

## 4. 首次使用

1. **扫码登录**：点击首页右上角「登录」，进入登录页，用 B 站 App 扫码。启动后也会在后台自动检查登录状态。
2. **登录态存储**（Windows）：
   - Cookie：`%APPDATA%\xiaoman\BiliTools\cookie\<mid>\qr_login.txt`
   - 多账号映射：`%APPDATA%\xiaoman\BiliTools\accounts.json`
3. **设置保存目录**：在「设置」页指定下载目录；默认目录由 `src/config/path.py` 决定。
4. **清晰度与账号**：4K / HDR / 杜比等档位依赖大会员权限；多账号分流时需先在各账号下登录过。

> 写操作（发评论、私信、老粉签约）需要有效登录和 `bili_jct`。

## 5. 运行测试

```bash
# 单元测试（不联网）
pytest tests/ -m "not network"

# 含真实网络测试
pytest tests/

# 前端离屏冒烟测试：验证各页面可构建、导航、主题、去重等
python frontend/pyside6/smoke_test.py
```

冒烟测试的结果写入 `output/logs/smoke_result.txt`，末尾出现 `SMOKE OK` 即为通过。

## 6. 打包为 exe（可选，仅 Windows）

```bash
pip install pyinstaller==6.22.0
build_exe.bat
```

脚本会自动关闭正在运行的 `BiliTools.exe`、调用 `pyinstaller bilitools.spec --noconfirm --clean`，并生成：

- `dist\BiliTools.exe`
- `dist\BiliTools-windows-x64.zip`（含 exe 与 `assets/fonts`、`assets/imgs`）

分发时保持 exe 与 `assets` 目录同级，否则界面字体或图标会缺失。

## 7. 常见问题

**Q：启动时报 `No module named PySide6`**
A：虚拟环境没装全依赖，执行 `venv\Scripts\activate` 后重新 `pip install -r requirements.txt`。

**Q：音视频合成失败**
A：确认 PATH 中有系统 ffmpeg；若没有，检查 `imageio-ffmpeg` 是否安装成功（它会提供内置 ffmpeg）。

**Q：接口返回 -403 / -412**
A：多为登录态或设备指纹缺失。重新扫码登录；若仍失败，检查 cookie 文件是否完整。

**Q：图标显示成小方框**
A：本项目 SVG 图标必须用 `fill="currentColor"` 的填充风格；描边（`stroke`）风格无法被当前图标渲染方式加载。

**Q：打包时 `WinError 5`**
A：有程序占用 `dist\BiliTools.exe`（资源管理器预览、杀毒软件、正在运行的实例）。关闭后重跑 `build_exe.bat`。

**Q：应用启动后没有窗口**
A：确认没有设置 `QT_QPA_PLATFORM=offscreen`（该变量用于离屏渲染/冒烟测试，会使窗口不可见）。
